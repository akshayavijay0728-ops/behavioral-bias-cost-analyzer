# Behavioral Bias Cost Analyzer for Indian Stock Portfolios

A complete, interactive standalone HTML application to analyze the financial impact of common behavioral investor biases in Indian stock portfolios.

## Features
- **Monte Carlo Portfolio Simulation**: Simulates portfolio returns and growth over time.
- **Behavioral Bias Simulation**: Model and quantify the cost of:
  - *Panic Selling* (loss aversion during market drops)
  - *Herd Mentality* (buying near market peaks, selling at troughs)
  - *Overconfidence* (excessive trading leading to transaction costs and slippage)
  - *Loss Aversion* (holding onto losing assets for too long)
- **Risk Dashboard**: Calculate Value at Risk (VaR) and Conditional Value at Risk (CVaR).
- **SHAP-style Explanations**: Understand the relative impact of each bias on your final portfolio value.
- **Downloadable Reports**: Generate and download reports directly from the browser.
- **No Server Required**: Fully client-side app, runs entirely in your web browser.

## How to Run
Simply open [index.html](index.html) in any modern web browser.
